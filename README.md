# NurseLight

A sanctuary app for nurses — philosophical quotes, guided meditation, mental health check-ins, and reflective journaling. Built to be a beautiful, spiritual experience.

## Getting Started

```bash
cd nurselight
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- **Home** — Daily philosophical quote, calming ambient design
- **Quotes** — 36 curated quotes across 6 categories (Stoicism, Compassion, Resilience, Mindfulness, Purpose, Healing) with a quote oracle
- **Meditate** — Guided breathing timer with 4 patterns and animated breathing orb
- **Wellness** — Multi-step mental health check-in with personalized affirmations and self-care suggestions
- **Journal** — Prompted reflective journaling with local storage persistence

## Tech Stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4
